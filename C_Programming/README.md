# C Programming Practice

This directory contains my C programming exercises and practice code.

The exercises focus on C syntax, language features, and basic algorithms. All programs are designed to be compiled and run on a PC.

## Topics

The contents include:

- C syntax and fundamentals
- Pointers and arrays
- Structures, unions, and enums
- Dynamic memory allocation
- File I/O
- Preprocessor and macros
- Standard library usage
- Data structures
- Basic algorithms

More exercises will be added as I continue learning C.
