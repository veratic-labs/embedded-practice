# STC89C52RC Practice

This directory contains my embedded programming exercises using an STC89C52RC development board.

The schematic of the development board and the STC89C52RC datasheet are also included in this directory for reference.

## Practice

The exercises currently include:

- LED
- Push buttons
- Matrix keypad
- 7-segment display
- LED matrix display
- Buzzer
- LCD display

More exercises may be added as I continue learning and experimenting with the STC89C52RC.
